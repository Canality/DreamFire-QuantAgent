# PA-style 横截面选股 × 统一21窗：预注册

> 本实验尚未查看收益结果。它是 DreamFire 为组合任务编写的 PA-style 适配器，不是 PA_Agent 原生能力。

## 假设

LLM 按 PA_Agent 的价格行为人设和逐棒检查原则，仅基于决策日前的结构化 OHLCV 特征，从49只股票中选择15只并给出相对分数；在相同 T2 仓位算法下，其组合收益/回撤可能优于 T2 的固定因子公式排序。

## 数据与窗口

- 使用不可变快照 `sina_20260721_135352`，49/49、6/6、500交易日。
- 使用 Phase A/B 相同的21个非重叠20日开发窗口；只可称开发集回放。
- 每窗特征只从 `history[:start]` 计算，不向模型提供测试窗行情、收益、标签、新闻或公司名称。

## 固定输入特征

每只股票仅提供：板块、5/20/60日收益、EMA20距离、EMA20五日斜率、ATR14/价格、20日区间位置、60日最大回撤、5日/20日量比、最近5根K线的实体方向/实体强度/收盘位置。CSI300提供同构市场摘要。

不得向模型提供 T2 composite、未来收益或历史窗口成败。PA 素材固定为上游 commit `71fbade` 的：

- `提示词大纲_人设与思维方式.txt`
- `逐棒分析检查单.txt`

运行产物记录两文件 SHA-256。

## 决策契约

- 模型：DeepSeek API `deepseek-chat` 非思考模式、temperature=0、JSON mode。
- 每窗一次组合决策调用；格式失败最多重试1次，连续失败3窗停止。
- 必须输出恰好15个唯一、股票池内 ticker，覆盖6个板块。
- 每项含 `score`（0–100）及仅引用输入字段名的 `reason_codes`；禁止使用模型外部知识。
- 任意契约失败则该窗失败关闭，不自动补股票。

## 仓位与回测

- 将模型 score 作为 `composite`，沿用 T2 的 `inv-vol × exp(0.20×clip(z,-2,2))` 配仓。
- 单股≤10%、板块≤25%、现金≥5%；最终权重再次断言。
- 首日开盘固定股数买入，末日收盘卖出，20日不再平衡。

## 对照与晋级门槛

主对照为 `phase_b_t2_score_alloc`，同窗配对：

- 中位收益差 ≥ +0.30pp；
- `0.70×收益 - 0.30×最大回撤` 胜率 ≥60%；
- 最近4窗至少赢3窗；
- 中位回撤恶化 ≤+0.30pp；
- 最差收益不得比 T2 再差超过1.00pp；
- 21/21窗与仓位约束全部有效。

同时报告 Jaccard 选股重合度、Token、缓存、延迟、费用。无论成败都保存全部窗口；不得修改提示词后覆盖本轮。
