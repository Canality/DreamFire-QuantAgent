# PA_Agent 与 PA-style 提示词决策验证结果

日期：2026-07-21

## 结论先行

**当前证据不支持用 PA_Agent 或 PA-style 自由提示词决策替代 T2 量化 pipeline。**

PA 原生流程与比赛任务存在结构错配：它面向单品种“当前是否存在具体入场机会”，在 CSI300 日线上倾向不下单；PA-style 横截面适配虽然便宜很多，但输出契约不稳定，且有效窗收益表现弱于 T2。提示词可以改善解释形式，但没有自动产生可验证 alpha。

## 实验 A：PA_Agent 原生两阶段判市

设计：每个决策日前最多100根 CSI300 日K进入 PA_Agent 原生 Stage1→router→Stage2；只允许缩放 T2 总敞口，不改变选股与相对权重。

### 工程结果

- 上游 commit：`71fbade`
- 上游选定安全测试：25 passed / 5 failed。失败显示 normalizer 会把部分本应拒绝的原始矛盾自动改写为合法结果。
- DreamFire 增加 raw JSON fail-closed 包装后运行21窗。
- 有效：16/21（76.19%）；失败：5/21。
- 16个有效输出方向：bullish 0、neutral 16、bearish 0。
- 第0窗重复运行一次成功、一次 Stage2 严格校验失败，说明 temperature=0 也不能保证决策复现。

### 资源

- 输入 Token：4,713,685
- 其中缓存命中：3,626,496；未命中：1,087,189
- 输出 Token：104,075
- 总 Token：4,817,760
- 窗口累计耗时：959.0秒
- 按2026-07-21 DeepSeek v4-flash公开价格估算：约0.192美元

### 收益归因

因只有16/21有效，PA-native 没有合法21窗成绩。为区分“Agent择时”和“固定降仓”，额外计算全21窗固定75% T2反事实：

- 中位收益差：-0.105pp
- 中位回撤差：-0.660pp（改善）
- 效用胜率：11/21 = 52.38%
- 最近4窗：2/4
- 最差收益差：+1.347pp（改善）
- 中位收益差 bootstrap 95% CI：[-0.740pp, +0.087pp]

固定降仓降低了回撤和尾部损失，但牺牲收益且未通过晋级门槛。这不是 PA 择时收益，因为所有有效 PA 动作都相同为 neutral。

## 实验 B：PA-style 49选15

设计：复用 PA 上游人设与逐棒检查原则；每窗只给决策日前固定 OHLCV 特征，DeepSeek JSON mode 从49只中选15只；再使用与 T2 相同的 score-tilted inverse-vol 配仓。

### 工程结果

- 21窗全部尝试。
- JSON/业务契约有效：17/21（80.95%）。
- 4窗失败：3窗重试后仍只覆盖5个板块；1窗先缺 reason_codes、重试后仍只覆盖5板块。
- 17个契约有效窗中，另有1窗因所选股票测试首日无有效开盘价而被统一回测器拒绝。
- 最终可回测：16/21；因此没有合法21窗候选成绩。

### 16个可回测窗的弱描述性证据

失败窗被排除，因此以下数字不得称为正式策略分数：

- 相对 T2 中位收益差：**-0.577pp**
- 平均收益差：-0.306pp
- 中位回撤差：+0.119pp（恶化）
- 效用胜率：8/16 = 50%
- 最近4个可用窗：2/4
- 最差收益差：-0.735pp（恶化）
- 中位收益差 bootstrap 95% CI：[-3.530pp, +3.489pp]
- 与 T2 选股平均 Jaccard：0.330

### 资源

- 输入 Token：292,972（缓存命中123,776）
- 输出 Token：17,316
- 总 Token：310,288
- 总耗时：115.9秒
- 估算费用：约0.029美元

PA-style 比原生 PA 节省约93.6% Token，但便宜并不等于有效；它既未达到业务覆盖要求，在有效子集上也没有收益优势。

## 对原始怀疑的回答

“让 Agent 看提示词自由决策，可能比 pipeline 量化分析收益更高”是一个合理假设，但本轮数据不支持：

1. 原生 PA 16/16选择不下单/neutral，无法区分市场状态；
2. 横截面 Agent 只在17/21满足输出契约，16/21可执行；
3. 可执行子集收益和回撤均弱于 T2；
4. LLM 输出存在温度为0仍不完全复现、重试仍违反板块约束的问题；
5. PA 原生 Token 是 T2 公式计算不可比拟的额外资源开销。

## 下一步规划

1. **停止“PA提示词直接替代选股公式”路线**，不为追求21/21而事后增加自动补股并重跑同一实验。
2. **保留 T2 作为组合生成器**。确定性代码负责49选15、配仓、可交易性与硬约束。
3. Agent 只在有独特信息优势时改变组合，例如 point-in-time 官方公告/新闻风险；任何动作必须引用证据并进入新的因果实验。
4. Agent 的近期比赛价值放在：Symphony真实规划、证据审计、失败关闭、决策解释和报告生成，而不是自由计算 alpha。
5. 若以后仍测试 LLM alpha，只允许“在 T2 top25 内受限重排”的低自由度方案，并预先定义缺失开盘/板块覆盖的确定性候选池；但鉴于本轮中位收益差为负，优先级低于继续研究可解释的量化因子和风险暴露。
