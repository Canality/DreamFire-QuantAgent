# PA_Agent 原生判市：资源护栏触发后的描述性续跑

## 为什么另开记录

原预注册的单窗输入 Token 护栏为 150,000。第 0 窗真实两阶段调用总输入 168,008 Token，因此原实验按规则停止，不能事后放宽门槛并继续声称是同一个确认性实验。

第 0 窗同时证明：原生流程在 fail-closed 外部校验器下可完成，耗时 41.172 秒；缓存命中 61,056、缓存未命中 106,952、输出 3,167 Token。按 2026-07-21 DeepSeek 官方 `deepseek-v4-flash` 美元价格粗估，该窗约 0.016 美元，21 窗线性费用约 0.34 美元，费用可接受但 Token 经济性较差。

## 续跑性质

- 这是同一提示词、同一映射、同一21开发窗的**描述性完成**，不是新的确认性实验。
- 不修改原预注册中的 PA-M1/PA-M2 映射和比较指标。
- 仍报告原成功门槛的结果，但无论通过与否，只能作为开发证据；第0窗结果已经可见，不能包装成盲测。
- 新增运行护栏：实际 API 费用粗估不超过 1 美元、总耗时不超过 30 分钟、连续失败 3 窗立即停止。
- 完整运行后必须报告 Token、缓存命中、延迟和与 T2 的收益/回撤配对明细。

## 已知 PA_Agent 上游问题

上游 commit `71fbade` 的选定安全测试为 25 passed / 5 failed：normalizer 会把部分本应拒绝的原始输出改写为合法结果。续跑使用项目外部的 `FailClosedJsonValidator`，在 normalizer 之前拒绝：

1. 截断或非法 JSON；
2. `不下单` 但仍携带价格；
3. `突破单` 缺少明确 entry basis。

因此，本实验验证的是“PA_Agent 原生提示词/编排 + DreamFire fail-closed 包装”，不能声称未经修改的 PA_Agent 已通过安全验收。
