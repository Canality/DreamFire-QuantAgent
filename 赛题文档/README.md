# 赛题资料索引

## 权威层级

1. 主办方最新书面通知或官网更新。
2. 官方原始文件：`上市公司列表.xlsx`、静态规则、提交要求、评审标准。
3. 答疑分享会原始文字稿。
4. `结构化笔记.md`：自动转录后的人工整理，只用于检索，不是规则原文。

## 当前已核事实

- `上市公司列表.xlsx` 实际为 49 家、6 板块；项目 contract 对该文件做 SHA-256 校验。
- 答疑口述/转录多处说“50 家”，与 Excel 不一致。本地运行暂以 Excel 为准，正式提交前必须向主办方确认。
- 静态介绍允许半仓/空仓；答疑提到公司权重和为 1，现金是否包含在内不明确。
- 静态介绍强调初赛客观回测；答疑强调报告完整性和可用性影响筛选。
- 资源评分文字的分项总额和具体得分规则存在 10/15、5/10 的内部矛盾。

这些冲突集中记录在根目录 `VALIDATION.md` 和代码 `SubmissionContract.unresolved_questions`。不得直接修改原始资料来“消除”冲突。

## 文件说明

- `赛题介绍.txt`、`提交要求.txt`、`评审标准.txt`：静态书面材料。
- `上市公司列表.xlsx`：当前股票池来源。
- `...文字稿.md`：答疑音频转录，可能有识别错误。
- `...结构化笔记.md`：便于阅读的派生笔记，开头有非权威提醒。

视频和音频中间文件已删除，避免仓库残留约 160 MB 重复素材；文字稿与结构化笔记保留。
